Code (Matlab) in development for spatial analysis of climate feedback.

A number of data files are too large for Github and must be downloaded separately from the original data providers, and then renamed according to the names
given in the code.

Instructions:

(1) Open the Load_EBAF4_2_ERA5_1deg_erf_mean_LGRAtmos_final.m matlab file and search for *.nc files. 
(2) If the *.nc files are not here, they are too large for my Github site. You need to download them from the original data sites.
(3) Run the Load_EBAF4_2_ERA5_1deg_erf_mean_LGRAtmos_final.m file from matlab.
